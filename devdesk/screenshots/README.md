# Screenshots

Replace these placeholders with your real screenshots (PNG), then commit them.

| File | What to show |
|------|--------------|
| `desktop.png`  | Full desktop: tiled terminals, polybar visible |
| `launcher.png` | rofi open (`Super+D`) |
| `theme-1.png`, `theme-2.png` | Same desktop after pressing `Super+N` (dynamic theming) |
| `cheatsheet.png` | `Super+F1` shortcut menu |

Take them with the built-in tool: `Print` (full) or `Shift+Print` (area).
They land in `~/Pictures/Screenshots/` — copy them here:

```bash
cp ~/Pictures/Screenshots/<file>.png ~/devdesk/screenshots/desktop.png
```
